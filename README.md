# 🍞 Sweet Bakes — Artisan Bakery & Confectionery

A responsive, single-page website for **Sweet Bakes**, a student-friendly artisan bakery and café located near GL Bajaj Institute of Technology and Management, Greater Noida. The site showcases the bakery's menu, story, testimonials, blog, and an interactive order/cart system with WhatsApp checkout.

🔗 **Live Site:** [bakeryshopglbitm.netlify.app](https://bakeryshopglbitm.netlify.app/)

---

## ✨ Features

- **Hero Section** – Eye-catching landing area with quick stats (baking time, real dairy butter, student discount).
- **Today's Highlight** – Featured "Chef's Signature" item spotlighted daily.
- **Testimonials** – Reviews from students and local residents in the GL Bajaj community.
- **Artisan Baking Menu** – Filterable categories: All Items, Breads, Pastries, Cakes, and Student Combos.
- **Student Discount** – Flat 15% discount for GL Bajaj students, applied automatically at checkout.
- **Our Baking Story** – Brand story section covering ingredients, pricing philosophy, and baking workshops.
- **Blog / From the Oven** – Recipe tips and baking guides (lamination, sourdough starters, fruit tarts).
- **Order & Contact** – Embedded Google Map, store hours, and a custom order form.
- **Shopping Cart** – Live cart with subtotal, student discount calculation, and total.
- **WhatsApp Checkout** – Orders can be sent directly via WhatsApp for quick confirmation.

---

## 🛠️ Tech Stack

- **HTML5** – Page structure and semantic markup
- **CSS3** – Styling and responsive layout
- **JavaScript** – Cart logic, menu filtering, and order form interactivity
- **Netlify** – Hosting and deployment

## 🚀 Getting Started

Clone the repository and open `index.html` in your browser, or serve it locally:

```bash
git clone <repository-url>
cd <repository-folder>
# Open index.html directly, or use a local server:
npx serve .
```

### Deployment

This project is deployed on **Netlify**. To deploy your own version:

1. Push the project to a GitHub repository.
2. Connect the repository to [Netlify](https://www.netlify.com/).
3. Set the build/publish directory to the project root (or `dist`/`build` if using a bundler).
4. Deploy 🎉
